The Quality of Effect

Effect is not positive or negative by itself. Effect is change. Meaning enters when the system meets an actor, an objective, a time horizon and a consequence.

Inspired by Robert Pirsig's inquiry into Quality, this method refuses the false choice between the classical system diagram and the lived experience of the system. We need both. Metrics tell us that something moved. Human judgment asks whether the movement was worthy.

Gestalt gives the analyst the wide-angle view. Systems thinking traces actors, resources, dependencies and flows. Negative-space analysis asks what should exist but does not. Causal modeling searches for mechanism. Competing hypotheses prevent the first attractive explanation from becoming doctrine.

Test the pattern

Pattern is not proof. Pattern generates hypotheses. Evidence earns conclusions. Toulmin exposes the warrant behind the claim. Bayesian updating changes confidence as evidence arrives. Red teaming attacks the model before reality does.

FRAME → OBSERVE → GESTALT → MAP → NEGATIVE SPACE → CAUSAL MODEL → COMPETING HYPOTHESES → TOULMIN → BAYES → RED TEAM → SYNTHESIZE → WATCH

Trace consequence

For each significant change, record: Cause → Effect → Affected Actor → Outcome → Valence → Time Horizon. Valence is positive, negative, neutral, mixed or unknown, but it is meaningless without perspective. Positive for whom? Negative against what objective? For how long? What happens three moves downstream?

The human gate

A system can be efficient and brittle, secure and unusable, innovative and irresponsible at the same time. Those tensions are signals. Quality requires attention to them.
